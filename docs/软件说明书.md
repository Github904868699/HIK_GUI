# HIK MVS 形状识别系统说明书

## 1. 软件概述
HIK MVS 形状识别系统是一套基于海康威视工业相机的检测工具，提供实时画面预览、颜色/形状识别、Modbus TCP 通讯以及友好的图形化界面，适用于产线在线检测或离线调试等场景。

## 2. 系统架构与主要模块
- **图形界面与控制面板**：使用 PyQt5 构建主窗口，包含视频预览、消息提示、Modbus 信息区以及颜色配置区域，可在运行时调节 HSV 阈值与目标形状。
- **图像采集线程**：`HikGrabber` 负责相机初始化、取流和帧率统计，采集到的 BGR 帧通过信号传递给界面线程进行绘制与识别。
- **识别算法**：对当前帧执行 HSV 分割、轮廓分析和形状分类，并支持对金色圆形的鲁棒检测，识别结果与颜色配置动态关联。
- **Modbus TCP 服务**：内置线程化 Modbus 服务器，使用 `ModbusRegisterModel` 管理保持寄存器，支持 0x03/0x06/0x10 功能码读写并在写入时触发拍照识别流程。
- **配置管理**：应用启动时读取 `config.json`，构建颜色列表、命令码映射以及 Modbus 监听参数，实现灵活的部署配置。

## 3. 功能特性
1. **实时取流与预览**：窗口左侧展示相机实时画面，叠加识别到的颜色-形状标签，并可在 FPS 指标区查看性能信息。
2. **多颜色 HSV 管理**：右侧面板按颜色分组展示 HSV 滑杆、掩膜窗口开关与目标形状勾选，实现在线调参与验证。
3. **金色圆形增强识别**：在常规 HSV 检测基础上，针对金色圆形物体引入 Hough 圆检测与颜色特征约束，提高高反射物体的识别稳定性。
4. **Modbus 通讯**：系统作为 Modbus TCP 服务器，响应外部主站的读写请求，写寄存器 0 触发一次识别，并在寄存器 1 返回编码结果。
5. **手动识别联动 Modbus**：点击“手动识别”按钮时，同步写入寄存器 0/1，按照与自动触发一致的握手流程更新结果，便于离线调试与主站联调。
6. **结果编码映射**：识别标签与输出寄存器编码的对应关系可在 `config.json` 中通过十进制或十六进制配置，支持不同产线协议需求。

## 4. 运行环境要求
- 操作系统：Windows 10/11（推荐）或兼容的 x64 Linux。
- Python 版本：Python 3.8 及以上。
- 依赖库：PyQt5、numpy、opencv-python、ctypes、json、socket 等（详见 `camera.py` 顶部导入）。
- MVS 运行库：运行于冻结模式时自动尝试从常见路径加载 Hikrobot MVS Runtime DLL；也可手工安装并配置环境变量。

## 5. 配置文件说明（`config.json`）
```json
{
  "server": { "host": "0.0.0.0", "port": 502 },
  "cmd_map": {
    "金色-圆形": "0x11",
    "木头-正方形": "0x12",
    "散热片-正方形": "0x13"
  },
  "colors": [ ... ]
}
```
- `server`：设置 Modbus 监听地址，默认监听本机 0.0.0.0:502。
- `cmd_map`：识别标签到寄存器编码的映射，支持十进制、十六进制或 JSON 扩展格式。
- `colors`：定义每种颜色的 BGR 显示色、HSV 上下限及默认形状开关，系统据此创建滑杆与掩膜调试工具。

## 6. 启动与操作流程
1. **安装驱动与依赖**：确保已安装 Hikrobot MVS SDK，并使用 `pip install -r requirements.txt`（如提供）或手动安装 PyQt5、opencv-python、numpy 等库。
2. **连接相机**：将海康工业相机接入同一网络/USB，确保 MVS 客户端可枚举到设备。
3. **启动程序**：在项目根目录执行 `python camera.py`，首次运行会读取配置并开启 Modbus 服务，同时自动打开相机取流。
4. **实时调参**：展开右侧对应颜色的分组，通过 HSV 滑杆调整阈值，可点击“XX 掩膜”弹出实时掩膜窗口辅助判断；使用形状勾选框限制输出结果范围。
5. **手动识别测试**：点击 Modbus 区域中的“手动识别”按钮，系统会按照握手协议写入寄存器 0=1、寄存器 1=0，完成一次识别后将寄存器 0 清零并在寄存器 1 写入编码结果，可直接配合同步监测的主站验证流程。
6. **外部触发识别**：主站向保持寄存器 0 写入数值 1 即可触发拍照流程，系统识别完成后将结果编码写入保持寄存器 1 并自动清零寄存器 0，等待下一次指令。
7. **查看提示信息**：识别成功后文字会显示在右下消息栏，同时终端也会输出调试日志，例如未找到结果编码或未检测到目标等提示。
8. **关闭程序**：退出时自动停止取流线程并优雅关闭 Modbus 服务，避免端口占用。

## 7. Modbus 通讯协议细节
- **寄存器约定**：保持寄存器 0 用作识别请求触发位，1 表示请求一次识别；保持寄存器 1 用于返回识别结果编码，低 16 位有效。
- **握手流程**：
  1. 主站或手动按钮将寄存器 0 置为 1；
  2. 系统立即清空结果寄存器 1 并执行识别；
  3. 识别完成后，将匹配到的编码写入寄存器 1；
  4. 系统自动把寄存器 0 复位为 0，等待下一次触发。
- **支持的功能码**：0x03（读保持寄存器）、0x06（写单寄存器）、0x10（写多个寄存器），错误请求会返回标准异常响应。

## 8. 识别算法原理
- **HSV 阈值分割**：根据配置的 HSV 范围生成掩膜，提取连通域轮廓并过滤掉面积过小或过大的候选目标。
- **形状判定**：通过轮廓逼近获取多边形顶点数量，结合圆度、长宽比、夹角等规则区分圆形、三角形与正方形。
- **金色圆形增强**：对金色通道额外执行 Hough 圆检测并在 LAB 空间验证颜色特征，降低高亮反光误检概率。
- **结果映射**：识别到的标签按配置映射到编码，并在界面消息栏展示中文标签列表，同时刷新 Modbus 寄存器输出。

## 9. 常见问题与排查
- **无法打开相机**：检查 MVS 驱动是否安装、相机是否被其他程序占用，可尝试点击“重连”按钮重新初始化取流。
- **Modbus 无法连接**：确认端口未被占用，查看界面状态栏显示的监听 IP/端口信息，必要时修改 `config.json` 后重启应用。
- **识别结果为 0**：可能未匹配到 `cmd_map` 中的编码，或当前帧未检测到目标；可通过掩膜窗口调整阈值或在终端查看提示日志。

## 10. 版本与维护建议
- 在每次调整 `config.json` 或识别算法后建议重新测试“手动识别”，确认 Modbus 握手与编码输出正常。
- 可根据产线需求扩展 `cmd_map` 编码或新增颜色配置，确保 `colors` 与实际物料保持一致。
- 建议在部署环境中将程序打包为可执行文件，并确认 DLL 搜索路径设置正确，以提高运行稳定性。
